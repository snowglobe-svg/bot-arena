# BotArena 🤖⚔️

BotArena is a decentralized, EVM-compatible arena battle DApp deployed on BOT Chain. Players can connect their web3 wallets, queue up wagers using native BOT tokens, and participate in provably fair on-chain bot duels.

## 🌟 Key Features
* **MetaMask Integration:** Instant wallet connection with automatic network switching to BOT Chain Testnet.
* **On-Chain Battles:** Smart contract-driven queue system ensuring transparent match resolution.
* **Cyberpunk UI:** Modern dark-mode web interface built for fast web3 interactions.
